# Lutreos Website

Public marketing site for **Lutreos LLC** — supported living services for people with developmental disabilities.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Brand fonts and assets from the Lutreos Brand Kit (Cobalt & Concrete)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand notes

- Wordmark is artwork (never typed as a font)
- Cobalt `#1F4B99`, White `#F7F7F5`, Concrete `#B7B5B0`, Ink `#141414`, Sky Wash `#8FA6C9`
- Typography: Barlow Condensed (labels), Barlow (UI), Newsreader (body)
